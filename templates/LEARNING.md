# Learning log

Short, durable lessons. One entry per surprise, failure or rule worth keeping.
Write what actually happened; mark guesses as guesses.

## Entry template

### YYYY-MM-DD - short title

- **What happened:** (observed behaviour, with command or file:line)
- **Why:** (root cause, or "unknown" plus the leading hypothesis)
- **Fix / evidence:** (commit, test name)
- **Rule from now on:** (one line an agent or person can follow)

## Rules collected so far

Promote rules that held up more than once. Remove rules that turned out wrong.
